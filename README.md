# unostudio

Web del estudio de diseño y desarrollo. Frontend en Next.js 16, React 19 y TypeScript, con Motion y un botón gratuito de Arc UI.

```sh
pnpm install
pnpm dev
```

```sh
pnpm lint
pnpm typecheck
pnpm build
```

La web incluye inicio, diseño web, software a medida, servicios, IA, proyectos y contacto. Presenta diez capturas en una tira automática, con ampliación, arrastre con ratón y alternativa sin movimiento. El footer azul ilustrado organiza los enlaces del estudio. No necesita variables de entorno, base de datos, autenticación ni servicios de IA.

Los logos y las capturas originales se conservan en `public`. El componente gratuito de Arc y sus tokens proceden de `https://uiarc.dev/r/button.json` y `https://uiarc.dev/r/arc-motion-tokens.json`. Las vistas públicas de 21st.dev se consultaron como referencias de interacción.

El repositorio es `luucabg/unostudio-org-last`. Su rama `main` está conectada a Vercel. Publicar cambios requiere subirlos a GitHub.

Los proyectos se capturaron el 23 de octubre de 2026 desde sus páginas públicas. Kavkasioni 33 conserva la versión antigua solicitada. La foto de Pexels y la ilustración original completa del footer están documentadas en `.impeccable/asset-provenance.json`.
