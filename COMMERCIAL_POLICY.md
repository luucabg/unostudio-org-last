# unostudio · política comercial actual

Documento interno. No publicar íntegramente en la web.

## Oferta pública

- Web de conversión: desde 1.800 € + IVA.
- Mantenimiento web: opcional, desde 79 €/mes.
- Sistema comercial: desde 1.500 € de implantación + 249 €/mes + IVA.
- Web + sistema: desde 3.000 € de implantación + 299 €/mes + IVA.

## Web de conversión

- Es un proyecto de pago único.
- No existe mensualidad obligatoria de unostudio.
- Referencia de cobro: 50 % al empezar y 50 % antes de publicar.
- El mantenimiento se ofrece aparte y nunca debe presentarse como necesario para conservar la web.
- Dominio, hosting, email, licencias y otros proveedores recurrentes deben ir a nombre del cliente siempre que sea posible.
- Si un proveedor tiene coste propio, se informa antes de aprobarlo.
- Tras el pago completo, se entrega la web y las cuentas acordadas según propuesta.
- Licencias de terceros, herramientas previas y componentes reutilizables conservan sus condiciones propias.

### Primeros clientes

Para los primeros 3 clientes web de pago se puede utilizar de forma privada un precio estratégico de 1.350 € + IVA si ayuda a cerrar un buen caso.

Reglas:

- nunca publicarlo en la web;
- no presentarlo como descuento permanente;
- mantener un alcance controlado;
- mantener 50 % / 50 %;
- priorizar clientes con potencial de testimonio, caso real y recomendación;
- no bajar de ahí por inseguridad.

## Diagnóstico

- La primera revisión para entender el problema y comprobar encaje no tiene coste ni compromiso.
- No regalar auditorías extensas, documentación o consultoría profunda.
- Si se requiere trabajo de análisis independiente, se presupuesta antes.

## Sistema comercial

- Implantación inicial + mensualidad.
- Sin permanencia anual por defecto.
- Tras la implantación: mes a mes con 30 días de preaviso.
- La mensualidad incluye alojamiento, monitorización, mantenimiento, soporte y evolución básica dentro del alcance.
- APIs, telefonía, mensajería, licencias, integraciones especiales y consumos extraordinarios se cobran aparte cuando corresponda.
- Los datos del cliente son exportables al finalizar.
- El software base, herramientas internas y componentes propios de unostudio no se transfieren salvo acuerdo expreso.

## Costes de terceros

Nunca asumir indefinidamente costes recurrentes de un cliente sin que estén incluidos de forma explícita en el precio.

Orden preferido:

1. cuenta y facturación a nombre del cliente;
2. unostudio configura y administra técnicamente si está contratado;
3. si un coste debe pasar por unostudio, debe estar presupuestado con margen y límites claros;
4. ningún consumo variable se absorbe de forma ilimitada dentro de una cuota fija.

## Reglas de confianza

- No hay costes ocultos.
- No añadir trabajo de pago sin aprobación.
- No inventar métricas, testimonios o resultados.
- No prometer ventas o leads concretos.
- No rehacer una web si una mejora parcial resuelve el problema.
- No vender el sistema si no existe un problema real de seguimiento.
- Explicar tecnología en términos de proceso y resultado, no de stack.
